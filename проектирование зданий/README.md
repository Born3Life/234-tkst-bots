# Проектирование зданий — Telegram бот

Эксперт по дисциплине «Проектирование зданий» для специальности «Строительство и эксплуатация зданий и сооружений».

## Возможности

- Помощь в AutoCAD: команды, чертежи, печать, оформление по ГОСТ
- Анализ чертежей и схем (по фото)
- Работа с проектной документацией (PDF, DOCX)
- Составление пояснительных записок
- Конструктивные расчёты и решения
- Ссылки на ГОСТ, СП, СНиП, ЕСКД, СПДС

## Запуск

```bash
# Установка
uv sync

# Настройка
cp .env.example .env
# Отредактируй .env — вставь DESIGN_BOT_TOKEN и OPENROUTER_API_KEY

# Запуск
uv run python -m bot
```

## Деплой на Render

1. Запушь репозиторий на GitHub
2. На Render.com создай нового Web Service через Deploy from Docker
3. Укажи путь к Dockerfile: `проектирование зданий/Dockerfile`
4. Добавь переменные окружения: `DESIGN_BOT_TOKEN`, `OPENROUTER_API_KEY`
