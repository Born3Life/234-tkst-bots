# Сметное дело — Telegram бот

Эксперт по дисциплине «Сметное дело» для специальности «Строительство и эксплуатация зданий и сооружений».

## Возможности

- Составление и проверка смет (ЛСР, ОСР, ССРСС)
- Анализ КС-2, КС-3, КС-6а
- Работа с ФЕР, ТЕР, ГЭСН, индексами
- Консультации по Гранд-Смете
- Нормативная база: МДС, Приказы Минстроя

## Запуск

```bash
uv sync
cp .env.example .env
# отредактируй .env
uv run python -m bot
```

## Деплой на Render

Web Service → Docker → Dockerfile Path: `estimate/Dockerfile`
Envs: `ESTIMATE_BOT_TOKEN`, `OPENROUTER_API_KEY`
