# Строительно-монтажные работы — Telegram бот

Эксперт по дисциплине «Строительно-монтажные работы» для специальности «Строительство и эксплуатация зданий и сооружений».

## Возможности

- Технология строительного производства (земляные, бетонные, каменные, кровельные, отделочные работы)
- Организация стройплощадки (ПОС, ППР, стройгенплан)
- Монтаж строительных конструкций
- Контроль качества и исполнительная документация
- Охрана труда и техника безопасности
- Анализ фото, чертежей и проектной документации

## Запуск

```bash
uv sync

cp .env.example .env
# Отредактируй .env — вставь SMR_BOT_TOKEN и DEEPSEEK_API_KEY

uv run python -m bot
```

## Деплой на Render

1. Запушь репозиторий на GitHub
2. На Render.com создай нового Web Service через Deploy from Docker
3. Укажи путь к Dockerfile: `SMR/Dockerfile`
4. Добавь переменные окружения: `SMR_BOT_TOKEN`, `DEEPSEEK_API_KEY`
