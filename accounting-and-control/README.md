# Учёт и контроль — Telegram бот

Эксперт по дисциплине «Учёт и контроль в строительстве» для специальности «Строительство и эксплуатация зданий и сооружений».

## Возможности

- Ответы на вопросы по сметам, СНиПам, исполнительной документации
- Распознавание и решение заданий с фото
- Работа с тестами, актами КС-2/КС-3, журналами работ

## Запуск

```bash
# Установка
uv sync

# Настройка
cp .env.example .env
# Отредактируй .env — вставь BOT_TOKEN и OPENROUTER_API_KEY

# Запуск
uv run python -m bot
```

## Деплой на Render

1. Запушь репозиторий на GitHub
2. На [Render.com](https://render.com) создай нового **Worker** через **Deploy from Docker**
3. Добавь переменные окружения: `BOT_TOKEN`, `OPENROUTER_API_KEY`
4. Деплой — бот запустится автоматически
